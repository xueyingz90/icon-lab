# ICON LAB · 资产与动效工作台

静态前端，直接由 GitHub Pages 托管。保留原有动效模块，新增资产库基础版。

## 资产库

上传 SVG → 补充元数据 → 入库 → 检索 → 详情与来源 → 下载复用。

支持本地试用与 Supabase 云端空间。云端通过邮箱密码登录，使用工作空间角色控制访问，支持原子版本更新与历史版本。当前所有资产均明确标记“已登记 · 未审核”。

开通步骤与待操作事项见 [部署说明](docs/SETUP.md)。默认 cloud-config.js 为空，因此初次打开为本地试用；不会声称云端已配置。

原工作台的数据仍保存在浏览器中；资产库的账号不会自动同步原动效项目。

## 开发

无需构建或生产依赖。用静态服务器打开根目录，不要直接双击 HTML。

开发测试：`npm install`，然后 `npm test`。不要把 node_modules 放到部署包。

Morphicons、GIFENC 依赖与许可证保留于 vendor/。
