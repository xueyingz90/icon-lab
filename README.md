# ICON LAB · 资产与动效工作台

静态前端，直接由 GitHub Pages 托管。保留原有动效模块，基础图标已合并到统一资产库。

## 资产库

上传 SVG → 补充元数据 → 入库 → 检索 → 详情与来源 → 下载复用。

支持本地试用与 Supabase 云端空间。云端通过邮箱密码登录，使用工作空间角色控制访问，支持原子版本更新与历史版本。上传资产保存后可直接复用，不设置强制审核。50 个内置图标统一作为“演示素材”展示，可显式复制到自己的资产，不会自动上传。

开通步骤与待操作事项见 [部署说明](docs/SETUP.md)。个人原型的 Supabase 连接已配置，数据库与 RLS 已部署。初次打开仍为本地试用；账号与同步入口从首页收起，通过个人设置书签访问。用户已确认真实登录和跨电脑同步验收完成。

原工作台的数据仍保存在浏览器中；资产库的账号不会自动同步原动效项目。

## 开发

无需构建或生产依赖。用静态服务器打开根目录，不要直接双击 HTML。

开发测试：`npm install`，然后 `npm test`。不要把 node_modules 放到部署包。

Morphicons、GIFENC 依赖与许可证保留于 vendor/。

## Figma 单图标同步

开发试用插件位于 figma-plugin/，可通过 Figma 桌面版导入 manifest.json。安装和验收见 [插件说明](figma-plugin/README.md)。插件复用同一后端，支持选区预览、来源关联、显式更新版本和只读权限拦截；暂未完成真实 Figma 客户端验收。

插件构建：`npm run build:figma`。分发包仅含本地代码和公开连接配置，无需团队成员安装 MCP。

当前审核策略见 [产品决策](docs/REVIEW_POLICY.md)：个人试用阶段不增加审批，未来团队推荐版本可采用规则检查、AI 辅助和按需人工确认。

## 图标规范

资产库新增“图标规范”，可按设备保存画布、描边、颜色与安全区要求。上传及详情自动展示当前规范的检查结果，不做强制审核或自动修图。云端规范属于工作空间，支持跨电脑读取、所有者修改、版本冲突拦截及历史保留；示例需保存后才生效。[使用与限制](docs/STANDARDS.md)。
