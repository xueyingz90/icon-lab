## 2. 规则等级与冲突处理

- **技术硬约束**：必须符合当前生成与安全校验能力，不得放宽或绕过。
- **已确认参数**：由人确认后固定，模型不得自行修改。
- **视觉规则**：用于构图与风格判断；需要例外时，应明确说明并人工确认。
- **单次语义要求**：定义本次图标表达什么、包含什么，不改变整个图标家族的规范。

技术硬约束和已确认参数优先。参考素材或单次要求与其冲突时，先报告冲突，不自动更换描边、颜色、端帽或留白。尚未填写的项目视为“待定义”，不能把建议值当成已确认规则。

## 3. 技术与参数基线

### 3.1 当前 Icon Lab 的硬约束

| 项目 | 约束 |
| --- | --- |
| 画布 | 24 × 24，viewBox 为 0 0 24 24 |
| 图形形式 | 单色、无填充的线性图标 |
| 描边宽度 | 0.5–4 个设计单位；生成时使用已确认的一个值 |
| 颜色 | 一个六位十六进制色值 |
| 端帽 | round / butt / square 三选一 |
| 连接 | round / miter / bevel 三选一 |
| 安全留白 padding | 0–5；曲线和完整描边必须在安全区内 |
| 输出 | 名称和路径 d；名称最多 80 字符，路径最多 12000 字符 |
| 路径命令 | 仅大写 M、L、C、Q、Z；不能包含 SVG 标签、样式、脚本或外链 |
| 风格说明 styleNotes | 最多 1000 字符 |
| 无效输出 | 最多一次修复；仍不合格则不保存为成功候选 |

结构与保守描边边界通过，不等于语义或视觉质量通过。

**设计单位与显示像素**：下文尺寸均按 24 × 24 的 SVG 设计单位填写。显示为 24px 时，一个设计单位对应一个显示像素；放大预览不能代替实际尺寸验收。

**安全留白与视觉留白不同**：padding 是不可越过的最低边界，视觉留白是家族构图目标。例如 padding=1 时，允许的描边安全区为 1–23，但可以要求主体实际外缘通常控制在 2–22。

测量视觉尺寸与间距时，默认按**完整描边的可见外缘**测量，不按路径中心线测量。以 round 端帽、2 单位描边为例，端点会沿切线向外延伸约 1 单位；曲线及尖角需结合实际形状判断。

## 4. 视觉一致性规则

每项均填写“确认规则 + 容差或例外 + 标准示例”。建议先选择少量稳定规则，不把所有建议同时设为硬门槛。

### 4.1 视觉尺寸与轮廓

| 项目 | 确认规则 |
| --- | --- |
| 主体可见宽高范围 | [填写；可从 18–20 单位试验，不要求所有形状同时达到相同宽高] |
| 通常的四周视觉留白 | [填写；可从约 2 单位试验] |
| 圆形主体的尺寸基准 | [填写参考图标及范围] |
| 方形主体的尺寸基准 | [填写参考图标及范围] |
| 细长 / 斜向主体的尺寸基准 | [填写参考图标及范围] |
| 光学尺寸补偿 | [哪些形状可略放大或缩小，允许多少，谁确认] |

正例：[同一排中视觉体量接近的图标]

反例：[边界框相同，但其中一个明显偏小或显得过满的图标]

判断重点：对比实际尺寸下的视觉体量，不只比较几何边界框。细长、圆形、复杂形状可以有不同几何尺寸，但不能突破安全区。

### 4.2 线条重量与连接

| 项目 | 确认规则 |
| --- | --- |
| 全部线条的统一描边 | [填写，与已确认 stroke 一致] |
| 开放线段的端点语言 | [填写，与已确认 cap 一致] |
| 转折连接语言 | [填写，与已确认 join 一致] |
| 线条交叉策略 | [连续交叉 / 按语义断开；分别说明适用情况] |
| 重合线条处理 | [避免重复描绘同一条边，避免意外局部加重] |
| 内外轮廓的重量关系 | [是否同粗；当前模式不能要求多种描边宽度] |

正例：[交叉与连接清晰、没有局部异常加重]

反例：[重复边、短线堆叠、交点形成不必要的黑块]

### 4.3 圆角与曲线语言

| 项目 | 确认规则 |
| --- | --- |
| 外框圆角 | [填写路径几何圆角半径或标准形；可从 2 单位试验] |
| 内部折线的转角 | [沿用 round join / 显式曲线；明确哪些情况采用哪种] |
| 小型结构的圆角例外 | [填写，避免圆角挤占内部空间] |
| 圆与圆弧 | [使用规则几何 / 指定曲线语言] |
| 有机曲线 | [允许的语义场景与参考；不允许则明确写出] |

round join 只决定描边连接方式，不等于路径本身具有固定圆角半径。外框若需要统一半径，必须单独定义几何规则。

正例：[同类外框使用一致的圆角语言]

反例：[同一家族中混用尖角、过软的大圆角和不规则曲线]

### 4.6 对齐、对称与光学居中

| 项目 | 确认规则 |
| --- | --- |
| 几何中轴 | [一般使用 x=12、y=12；说明例外] |
| 对称对象 | [如日历、文件、正面设备，是否要求左右对称] |
| 非对称对象 | [如钥匙、斜向箭头，采用什么视觉平衡基准] |

| 内部线段对齐 | [相同边距、同一分隔线高度、重复元素等距] |

正例：[与邻近图标并排时不偏斜、不下坠]

反例：[数学中心对齐，但一侧体量过重；装饰突出导致主体显得偏移]

对称适用于对象本身具有对称语义的情况，不要求所有图标强行对称。光学位移不能突破安全区。
