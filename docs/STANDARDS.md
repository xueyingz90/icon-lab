# 图标规范与自动检查

## 使用

1. 在资产库点击“图标规范”，选择通用、App、AI 眼镜或其他设备。
2. 按实际要求设置名称、画布宽高、允许描边粗细、允许颜色、是否允许渐变、四周最小留白。示例仅是草稿，不会自动应用。
3. 点击“保存并应用”。上传 SVG、查看资产或演示素材详情时，展开规范检查可看结果。检查提示不阻止保存，也不自动改动图形。

可以只启用需要的检查。设备有专用规范时优先使用，否则使用已保存的“通用”规范；两者都没有时显示未设置，不将示例当作团队标准。

本地试用的规范仅在本浏览器保存；登录云端后，规范属于当前工作空间，可以跨电脑共用。云端只有空间所有者可修改，其他成员可查看。切换电脑后登录同一工作台账号并选择同一空间，点击刷新获取最新规范。不会把本地规范自动上传到云端。

## 结果如何理解

- **未发现规范偏差**：当前可检查的项目未发现偏差，不代表 AI 或人工批准。
- **提示**：尺寸、可读取颜色、描边或安全区存在可定位的偏差。
- **需人工确认**：目前无法可靠计算或解释，比如圆弧、裁剪/蒙版、非等比描边、转轮廓描边、复杂连接边界或颜色变量。
- **未设置规范／规范暂不可用**：仍会进行基础 SVG 检查，不给出设计规范通过结论。

画布和留白按 SVG viewBox 的设计单位检查，不会自动缩放到目标画布。描边检查使用继承后的数值，等比变换按变换后粗细比较，容差 0.05；转轮廓图形无法可靠反推原始描边。颜色检查比较基础颜色或 currentColor 标记，不约束透明度；允许渐变时检查可读取的色标，不评估视觉质量。

安全区计算考虑可支持的几何与变换、部分描边边界，并保留 viewBox 的原点。复杂边界显示人工确认。几何计算复用仓库内的 Morphicons 路径转换，曲线边界使用三次曲线极值；圆弧等近似计算不会作为安全区通过的依据。

## 版本与追溯

每次规范修改增加规范版本，并保留不可变历史；内容相同不新增版本。保存时会检查编辑时的版本，防止覆盖其他电脑刚保存的规范，遇到冲突请“重新载入”。

详情中的结果明确针对**当前规范版本**计算，不是入库时的历史检查报告。规范更新不会修改 SVG、资产版本或原始版本历史。当前未接入 AI 审核，也不做强制审批。

Figma 同步插件仍可使用原安装包；同步后的资产在网页详情中按当前空间规范检查。本次未增加插件内的规范编辑或检查界面。

## 部署与验证

现有个人试点项目已部署，无需用户运行 SQL。新环境先应用 backend/001_asset_library.sql，再应用 supabase/migrations/20261031112854_icon_standards.sql。迁移最初通过官方 CLI 创建，文件时间戳已对齐已应用的云端迁移记录。

新增 il_standards 与 il_standard_versions，均开启 RLS。认证成员只能读取所属空间；写入经过受控 RPC，只有所有者可修改。前端继续使用公开连接 Key 与用户会话，无管理员密钥。

16 项自动化测试通过，覆盖规则、曲线边界、继承、云端/本地隔离、故障提示、权限与版本冲突。真实 Supabase 事务回滚测试验证了创建、更新、去重、历史、跨用户隔离、编辑成员写入拒绝及匿名拒绝；测试数据已回滚，原资产数量和版本数量未变化。未完成真实浏览器视觉截图验收或两台电脑的规范保存实测。

安全检查没有新增的规范表权限告警。既有 Auth 提醒为未开启[泄露密码保护](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)；性能检查仅提示部分索引尚未使用，见[官方说明](https://supabase.com/docs/guides/database/database-linter?lint=0005_unused_index)。本次未调整这些既有配置。
