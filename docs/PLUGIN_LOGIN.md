# Figma 记住登录 · v0.4.1

更新插件后，勾选“记住登录（仅此设备）”并登录一次。重新打开时会恢复并验证会话、加载已有工作空间；查询或上传前若会话即将过期，会自动续期并保存新令牌。默认不勾选，适用于共用电脑。

已登录时也可勾选保存，或取消勾选清除记忆。取消后当前运行仍能使用，下一次打开需重新登录；“退出”会清除本机记录并请求撤销当前服务器会话。断网时本机清除仍可完成，服务器撤销需网络可用。

会话仅允许保存 access_token、refresh_token、expires_at、用户 ID 和邮箱，不保存密码或无关用户元数据。存储位于 [figma.clientStorage](https://developers.figma.com/docs/plugins/api/figma-clientStorage/)，按插件 ID 隔离，不写入设计文件，也不跟随安装包跨电脑同步。该存储是本机存储，不是系统钥匙串或加密保险箱；共用设备应不勾选。插件 ID 改变或清理本机缓存后，需再次登录。

根据 [Supabase 会话规则](https://supabase.com/docs/guides/auth/sessions)，续期后 refresh token 可能轮换。本版在每次续期前读取本机最新记录，续期后保存新令牌；临时断网、服务异常不立即丢弃记忆，可点击“重试恢复登录”。会话已撤销、凭据不再有效时清除旧会话并要求登录。没有更改服务器会话有效期或访问权限。

主线程的存储消息与原插件使用同一运行桥接标识，存储键绑定现有后端，只写入白名单字段；读写/清除按顺序执行，避免晚到的保存覆盖退出清理。CloudClient 拦截已退出或换账号后的过期续期结果，旧请求的 401 不清除新账号。

原来的选区预览、确认上传、重复更新、版本冲突和资源库插入路径保留。没有数据库迁移，不需要重新注册账号或配置 Key。

验证：27 项自动化测试通过，含实际打包 UI 与主线程跨重启模拟、令牌轮换、断网重试、失效清除、默认不持久化、存储失败与队列竞争，以及原上传/调用回归。真实 Chrome 检查了登录和登录后的 420px 排版，无未捕获脚本异常。真实 Figma 中请更新后勾选登录，关闭插件并重开确认一次。
