# 单色面形生成 · v0.6.0

网页和 Figma 插件的目标规范均新增图形结构：线性 / 面形。旧项目未记录 renderMode 时仍按线性处理；面形记录 renderMode=filled 和 fillRule=evenodd。

## 支持条件

- 单色纯填充，颜色为六位十六进制；无描边。目标画布宽高 1–4096，可为矩形，安全留白小于短边一半。
- 每个子路径必须显式以 Z 闭合，拥有非零有向面积；镂空由同一复合路径的嵌套轮廓和 evenodd 规则产生。模型不能通过改 fill、stroke、颜色或校验状态绕过用户目标。
- 与线性共用安全的 M/L/C/Q/Z 绝对路径协议，最多 32 个子路径、128 段。拦截开放、退化、重复抵消、越界和不安全路径；无效模型结果最多修复一次。
- 预览、原尺寸 SVG、PNG、保存项目及插件插入均保留填充和镂空规则。修改目标不会重绘旧候选，需重新确认和生成。
- 原生插件识别到填充且无描边时预选面形，填充色混用时留空待指定；容器背景不视为图标填充。参考仍限定一个图标画板。

## 当前边界

不支持多色、渐变、阴影、填充加描边混合生成。evenodd 会使交叠轮廓的交集成为透明区域，因此模型需使用合并后的外轮廓，不能靠叠放多个填充形状拼接。自动校验不是拓扑或审美证明：复杂自交、极细细节、语义、视觉重心和相似风格仍需人工检查。零有向面积的自交轮廓会被保守拒绝。

## 验证

350 项自动检查通过，包含新增面形协议、闭合/面积/镂空规则、一次修复、网页模式切换/候选冻结/保存/导出/重载和真实打包插件 UI 与主线程的模拟联调。测试模型和 Figma API 为模拟；真实 AI 面形生成与 Figma 客户端插入需单独记录，不能据此宣称已实测通过。

插件更新：关闭旧插件，备份原目录后替换 code.js 和 ui.html，保留原 manifest.json 的真实插件 ID；重新运行应见 v0.6.0。

规范依据：[SVG 2 填充与镂空规则](https://www.w3.org/TR/SVG2/painting.html#WindingRule)。
