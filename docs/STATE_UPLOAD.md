# 状态素材卡片直接上传（v0.6.2）

左侧“起始”“目标”卡片改为可聚焦的按钮。点击任意位置即可打开对应状态原有的文件选择器；也可将一个 SVG 或 PNG 拖到对应卡片。上传成功后更新缩略图、名称、预览及下拉选择，沿用现有本地保存机制。文件失败时保留原素材。

每个卡片处理一个文件，多文件拖入取第一个。继续沿用现有导入限制：SVG 最大 1MB；PNG 最大 4MB，最长边不超过 4096px。原下拉与下方上传入口保留。

只调整 app.js、style.css、index.html 的网页交互及资源缓存版本，未改变 Figma 插件、资产库上传 API 或数据库。这次界面修改无需额外 SQL；此前 v0.6.0 的分类迁移仍按原部署说明执行。

验证：22 项自动化测试通过；在真实 Chrome 中确认卡片打开正确的原生文件选择器、SVG 导入、PNG 拖放与实际解码、起止状态独立更新，以及刷新后恢复素材。1440×900 和 1280×720 无页面横向溢出或未捕获脚本异常。

本版经 GitHub Pages 发布；当前运行结果见 DEPLOYMENT.md。刷新页面后，新版 app.js 与 style.css 的缓存标记为 20261031-sidebar-10。

左侧五个工作模式菜单改为纯文字，共享同一文字起点。桌面实际检查五项文字的 x 坐标均为 33px，项目资产数量保留；窄屏菜单支持文字横向滚动。
