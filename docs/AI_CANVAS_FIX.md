# AI 自定义画布与规范读取修复

日期：2026-11-08
状态：自定义画布已部署并完成真实验收。32×32 与 48×32 均成功生成三个候选、保存及导出。

## 本次修改

- 移除 AI 规范、生成提示、描边边界和 SVG 导出中的固定 24×24 限制。
- 支持方形或矩形画布，宽高为 1–4096 SVG 设计单位。提供 16、24、32、48、64 预设、自定义宽高和“跟随参考”。
- 单一尺寸的参考在首次载入或上传后可作为目标尺寸；混合尺寸需要人工选择。
- 兼容旧项目的数字 canvas；明确的数值字符串、宽高对象、两项宽高数组统一规范化。缺失、无效和越界尺寸继续拒绝。
- 描边上限和留白范围随短边计算；路径和描边按实际宽、高分别检查。
- 生成候选保留生成时画布。修改目标尺寸会使确认失效，不改变已有候选；重新确认后才可生成。
- SVG 原尺寸导出保留 width、height、viewBox；预览、实际尺寸展示和 PNG 导出保留矩形比例。
- 修改后的目标尺寸、候选规范、已保存项目及参考信息可跨页面切换和重新打开恢复。
- 规范分析提示提供完整响应示例；接受完整 spec 对象及同字段的完整扁平响应，不以默认值替代缺失字段。
- 分析校验失败时最多请求一次修复；仍失败则明确报错，不开放确认或生成。
- 生成画布是用户的明确设置，由服务端锁定，不委托模型推断；模型只分析风格字段，描边、颜色、留白等仍严格校验，不填默认值。诊断只记录结构类型，不记录完整模型内容、素材、描述或凭据。
- 动效模块的原有内部坐标系统保持原逻辑；本轮取消的是 AI 生成的固定画布限制。
