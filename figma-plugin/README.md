# Icon Lab · 图标工作台 v0.6.0（开发包）

三个入口：上传图标、资源库、AI 生成。上传和重复版本确认沿用 v0.4.4；新增选区 AI 生成。无需安装 MCP，也不在插件内填写模型密钥。

## 更新已有插件

关闭正在运行的插件，备份原安装目录，再用新版 code.js、ui.html 覆盖同名文件。保留原 manifest.json 中 Figma 分配的 ID；新包的主入口和允许访问域名与旧版一致。重新运行后底部应显示 **v0.6.0 · 选区 AI 生成**。

不要直接编辑打包后的 code.js / ui.html 后再构建；构建会覆盖它们。原主线程代码已移入 src/main.js，新增 AI 主线程在 src/ai-main.js，界面控制在 src/ai.js。

首次安装：在 Figma 桌面版 Plugins → Development → Import plugin from manifest 导入本文件夹的 manifest.json。若需要正式 ID，先创建 Development 插件并保留客户端分配的 ID。当前为本地开发包，未上架 Community。

## AI 生成

1. 使用工作台账号登录。AI 仍受服务器的用户白名单限制；能上传不代表已获 AI 权限。
2. 切换 AI 生成，选中一个图标 Frame / Component / Instance，点击“读取选区”。这一步只在本地导出 SVG 和预览。
3. 查看原始尺寸、描边与颜色；展开目标规范。混用或未识别字段需指定目标，安全留白 1 是待确认预设，不是自动测量值。支持单色线性和面形。纯填充且没有描边的选区会预选面形；也可在图形结构中手动切换。面形不要求描边、端点或连接，每个轮廓须闭合，镂空统一采用 evenodd。暂不生成多色、渐变或填充与描边混合图标。
4. 可选择“AI 分析风格”，也可人工确认完整规范。首次发送前须勾选授权；AI 建议需要检查后确认。
5. 填写图形描述与使用场景，最多 2000 字符。Enter 换行，⌘ / Ctrl + Enter 生成三个候选。
6. 选中候选，点击“插入所选图标并准备入库”。结果是独立的可编辑矢量，放在参考右侧，不覆盖原图，支持撤销。
7. 插件切回上传页，重新读取结果，并将生成摘要填入备注。核对当前文件链接和分类，另行点击“确认同步到资产库”。插入不会自动入库。

连接复用同一账号已保存的个人 Qoder；没有个人配置则使用团队接口。个人配置失效时不会自动转用团队额度。“管理个人 Qoder 配置”打开工作台；插件不会获取或存储 PAT。

原始参考、目标规范和候选状态分别处理。选区或内容变化会使参考失效；目标参数、需求或账号变化会拦截过期结果。插入后原生成批次仍可查看，继续生成需重新读取当前参考。

生成记录（需求、规范、来源节点、模型及时间）保存在结果节点的 iconlab.ai.v1 插件数据中。现有云端备注最长 500 字符，本版上传仅附摘要，完整记录仍在 Figma 节点，不承诺云端保存完整 AI 元数据。

## 原有上传与资源库

- 上传单个图标，确认名称、状态、分类及当前文件链接。选区变化不会自动上传；提交前再次导出核对。重复资产和版本冲突保留原确认流程。
- 登录同一空间，按名称、结构、风格检索资源，每页 24 项，可继续加载。只读成员可查找和插入 SVG，入库仍需编辑权限。
- 普通插件通常不能自动取得文件 Key，文件链接可能需要手填；节点 ID 从当前选区读取，手填链接的所属文件由用户核对。
- SVG 插入得到矢量图层，不等于团队组件实例。PNG 插入、组件更新、批量 AI 生成和整张产品页面分析均未实现。
- 可选记住登录，仅保存在本机、同一插件 ID 下。退出或取消记住会清理本机记录，不保存密码。

## 构建

```sh
npm run build:figma
npm test
```

构建将 src/ui.template.html、界面模块、共享校验及路径解析器合并到 ui.html，将 src/ai-main.js 和 src/main.js 合并为 code.js。无远程脚本，无新增浏览器依赖。网络仅允许既有 Supabase 域名。

插件调用独立 icon-ai-figma 云端接口，处理 Figma 的请求来源；网页接口仍保留精确来源白名单。两端共享登录验证、AI 用户白名单、个人配置及模型校验。接口标记不是权限凭据，实际授权依赖验证后的用户 JWT。

## 验证范围

完整自动检查 350 项通过，包括真实打包 UI 与主线程的模拟联调：32×32 / 48×32、授权、长描述、候选校验、原图保留、插入和撤销边界、原上传复用、内容变化、过期结果、成员权限与接口来源。模型与 Figma 场景为模拟；不能据此宣称真实客户端 AI 全链路验收通过。

客户端验收请使用公开测试图标，检查真实读取、生成、可编辑性、撤销和入库。个人 PAT 的调用另需成员本人填写后验证。
